System Critique - Heuristic Evaluation

While exploring and using the website I decided to look for material related to the Israel-Palestine Conflict and campus opinions surrounding it. For this search I mainly used the search feature, but also explored the various drop down access menus for commonly accessed topics. While exploring the system I noticed many strengths and weaknesses mixed throughout the website. The system overall had good user control and was consistent in its display and standards of display for the information provided. However, while exploring the page according to the topic I often found that my searches yielded irrelevant information and results. This caused some frustration that was furthered when I realized there was no way to sort the keyword search results other than how they were originally presented. This resulted in reduced efficiency as I had to manually sort through results to find relevant or recent information.

System Evaluation Summary

Strengths

  • Consistent Design with Good User Control
  • All articles included a title, author, date of publication, beginning sentence of article, and an image if attached.
  • Easy access to return to the home page by clicking the logo at the top of the page.
  • Flexibility and Efficiency
  • Drop down menus for common topic searches and articles tagged with their appropriate topics.

Weaknesses

  • No Help or FAQ
  • There was no accessible help or FAQ page, and even the “About” section of the system was sparse.
  • Error Loading Page without a Redirect to Information
  • The link “Advertise” under the “About” drop down menu led to an error loading page and did not redirect the user to the working link.
  • Faults in Minimalist Design and Efficiency
  • Results from a keyword search would include irrelevant articles despite seemingly sorting the results by relevance. Results under the “Politics” button under the menu did not contain any recent articles despite recent articles being published that should have been tagged to show here.
  • Loss of Flexibility and Control
  • The results of a keyword search seemed to be sorted by relevance, but there was no option to sort the results in any other way, such as chronologically.

Observations

As I observed my friend navigate the website to complete the tasks and investigate, it became clear that he was frustrated while trying to keyword search using the search feature. He seemed to enjoy looking at older articles using the archives drop down menu. While exploring and searching on the system it became clear that my friend did not find the system a useful resource for the given tasks. However, despite these drawbacks he did seem to find the website easy to navigate.

Comparing Results

In comparing the user experience my friend had and the experience I had while reviewing the website and system there seemed to be some things in common. Based on my review and the usability test there was an agreement on the inefficiency of the search feature. Despite the accessibility of the system, the current drawbacks seemed to bring down the overall impression of the system. There seems to be an agreement that in its current state we would not recommend using the system in the ways described in the tasks.
